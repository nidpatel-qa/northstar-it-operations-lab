# Security Operations

## Overview

The Security Operations section of the Northstar IT Operations Lab demonstrates a controlled approach to investigating suspicious authentication activity.

The investigation follows a simplified security operations workflow:

**Alert → Triage → Evidence Analysis → User Validation → Risk Assessment → Response → Closure**

All security events, usernames, IP addresses, timestamps, and investigation results are fictional and created for portfolio simulation.

## Authentication Investigation

### `Authentication-Investigation.md`

The investigation examines a simulated authentication alert involving:

- Multiple failed login attempts
- A successful authentication
- MFA validation
- Source network information
- User confirmation
- Risk assessment
- Incident classification
- Response and closure
