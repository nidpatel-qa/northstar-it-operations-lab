# Northstar IT Operations & Security Lab

## Project Overview

The Northstar IT Operations & Security Lab is a controlled portfolio project demonstrating practical IT support, systems troubleshooting, PowerShell automation, network diagnostics, and security operations concepts.

The project simulates a small corporate IT environment and uses fictional systems, users, network information, authentication events, and diagnostic results.

The goal is to demonstrate how an IT support or junior security analyst can investigate technical issues, analyze evidence, document findings, and determine appropriate next steps.

## Project Areas

### 01 — Company Environment

Documents the fictional Northstar corporate IT environment, including infrastructure, systems, users, and operational context.

**Demonstrates:**

- IT environment documentation
- Infrastructure awareness
- Enterprise IT concepts
- Technical documentation

### 02 — Service Desk

Demonstrates structured IT incident management using simulated support scenarios.

Included investigations:

- Windows performance troubleshooting
- Network and DNS troubleshooting
- Security authentication investigation

**Demonstrates:**

- Incident management
- Troubleshooting methodology
- Root-cause investigation
- Ticket documentation
- Escalation decisions

### 06 — PowerShell Toolkit

Demonstrates basic PowerShell automation concepts for IT support and troubleshooting.

Included tools:

- `System-Health.ps1`
- `Network-Diagnostics.ps1`

The scripts demonstrate endpoint health assessment, network troubleshooting, DNS concepts, conditional logic, and diagnostic decision-making.

**Demonstrates:**

- PowerShell fundamentals
- Windows troubleshooting
- Network diagnostics
- DNS troubleshooting
- Basic automation
- Conditional logic

### 07 — Security Operations

Demonstrates a controlled security investigation involving suspicious authentication activity.

The investigation follows:

**Alert → Triage → Evidence Analysis → User Validation → Risk Assessment → Response → Closure**

**Demonstrates:**

- Security alert triage
- Authentication investigation
- MFA analysis
- Evidence evaluation
- Risk assessment
- Incident classification
- Security incident documentation
- Response and escalation decisions
